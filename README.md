Project - 
This project analyzes the technological shift in the newspaper industry.
It provides insights into digital adoption and audience engagement.
The goal is to support strategic decision-making for media transformation.
This helps newspapers evolve and thrive in the digital age.

Tools used -

 
MYSQL Workbench( primary and secondary analysis)

Python (visual insights)

powerbi (Interactive dashboard)
